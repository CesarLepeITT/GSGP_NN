\section{\protect\bigskip 1. Suma ponderada de herencias, sin funci\'{o}n de
activaci\'{o}n ni promedio}

Comencemos con la suma ponderada (sin el promedio) para que gamma no est\'{e}
acotada a $[-1,0)\cup (0,1].$ 

En el nodo $n$ de la iteraci\'{o}n $k$ se tiene

\[
So_{n,k}=\alpha _{0,n,k}Sp_{n}+\dsum\limits_{i=1}^{N}\alpha
_{i,n,k}So_{i,k-1}+ms_{n,k}\left( RT1_{n,k}-RT2_{n,k}\right) 
\]

Sustituyendo cada sem\'{a}ntica por un vector $v$, de la forma

\[
v_{0,k}=Sp_{n},\text{ \ \ \ \ \ }v_{i,k}=So_{i,k-1},\text{ \ \ \ \ }i\in
\{0,1,2,...\}
\]

se obtiene

\[
So_{n,k}=\dsum\limits_{i=0}^{N}\alpha _{i,n,k}v_{i,k}+ms_{n,k}\left(
RT1_{n,k}-RT2_{n,k}\right) 
\]

Sustituyendo el $ms$ por $\alpha _{N+1,n,k}$, ya que este ser\'{\i}a el $N+1$%
-\'{e}simo vector y haciendo lo mismo con $RT1_{n,k}-RT2_{n,k},$de la forma

\[
\alpha _{N+1,n,k}=ms_{n,k},\text{ \ \ \ \ \ \ }v_{N+1,k}=RT1_{n,k}-RT2_{n,k}
\]

Se obtiene

\[
So_{n,k}=\dsum\limits_{i=0}^{N+1}\alpha _{i,n,k}v_{i,k}
\]

La cual expresa la sem\'{a}ntica en el nodo $n$ y la iteraci\'{o}n $k$ como
una combinaci\'{o}n lineal de la sem\'{a}ntica del nodo anterior y la
perturbaci\'{o}n $RT$ actual.

\bigskip 

Para simplificar, comencemos con la capa $k=0$, en la cual se calculan las
sem\'{a}nticas, siguiendo la f\'{o}rmula original de GSGP:

\[
So_{1,0}=Sp_{1}+ms_{1,0}\left( RT1_{1,0}-RT2_{1,0}\right) 
\]

\[
So_{2,0}=Sp_{2}+ms_{2,0}\left( RT1_{2,0}-RT2_{2,0}\right) 
\]

\[
...
\]

\[
So_{N,0}=Sp_{N}+ms_{N,0}\left( RT1_{N,0}-RT2_{N,0}\right) 
\]

\bigskip La primera capa de la red $k=1$ ya utilizar\'{\i}a la f\'{o}rmula
modificada

\[
So_{1,1}=\alpha _{0,1,1}Sp_{1}+\dsum\limits_{i=1}^{N}\alpha
_{i,1,1}So_{i,0}+ms_{1,1}\left( RT1_{1,1}-RT2_{1,1}\right) 
\]

\[
So_{2,1}=\alpha _{0,2,1}Sp_{2}+\dsum\limits_{i=1}^{N}\alpha
_{i,2,1}So_{i,0}+ms_{2,1}\left( RT1_{2,1}-RT2_{2,1}\right) 
\]

\[
...
\]

\[
So_{N,1}=\alpha _{0,N,1}Sp_{N}+\dsum\limits_{i=1}^{N}\alpha
_{i,N,1}So_{i,0}+ms_{N,1}\left( RT1_{N,1}-RT2_{N,1}\right) 
\]

Y definiendo

\[
v_{0,n,1}=Sp_{n},\text{ \ \ };\text{\ \ \ }v_{i,n,1}=So_{i,0}\text{ \ };%
\text{\ \ \ \ }i\in \{1,2,...,N\}\text{ \ \ \ };\text{ \ \ \ }\alpha
_{N+1,n,1}=ms_{i,1}\text{ \ \ };\text{\ \ \ \ }%
v_{N+1,n,1}=RT1_{n,1}-RT2_{n,1}
\]

\bigskip Obtenemos

\[
So_{1,1}=\dsum\limits_{i=0}^{N+1}\alpha _{i,1,1}v_{i,1,1}
\]

\[
So_{2,1}=\dsum\limits_{i=0}^{N+1}\alpha _{i,2,1}v_{i,2,1}
\]

\[
...
\]

\[
So_{N,1}=\dsum\limits_{i=0}^{N+1}\alpha _{i,N,1}v_{i,N,1}
\]

La segunda capa de la red $k=2$ se define como

\[
So_{1,2}=\alpha _{0,1,2}Sp_{1}+\dsum\limits_{i=1}^{N}\alpha
_{i,1,2}So_{i,1}+ms_{1,2}\left( RT1_{1,2}-RT2_{1,2}\right) 
\]

\[
So_{2,2}=\alpha _{0,2,2}Sp_{2}+\dsum\limits_{i=1}^{N}\alpha
_{i,2,2}So_{i,1}+ms_{2,2}\left( RT1_{2,2}-RT2_{2,2}\right) 
\]

\[
...
\]

\[
So_{N,2}=\alpha _{0,N,2}Sp_{N}+\dsum\limits_{i=1}^{N}\alpha
_{i,N,2}So_{i,1}+ms_{N,2}\left( RT1_{N,2}-RT2_{N,2}\right) 
\]

Y definiendo

\[
v_{0,n,2}=Sp_{n},\text{ \ \ };\text{\ \ \ }v_{i,n,2}=So_{i,1}\text{ \ };%
\text{\ \ \ \ }i\in \{1,2,...,N\}\text{ \ \ \ };\text{ \ \ \ }\alpha
_{N+1,n,2}=ms_{i,2}\text{ \ \ };\text{\ \ \ \ }%
v_{N+1,n,2}=RT1_{n,2}-RT2_{n,2}
\]

\bigskip Obtenemos

\[
So_{1,2}=\dsum\limits_{i=0}^{N+1}\alpha _{i,1,2}v_{i,1,2}
\]

\[
So_{2,2}=\dsum\limits_{i=0}^{N+1}\alpha _{i,2,2}v_{i,2,2}
\]

\[
...
\]

\[
So_{N,2}=\dsum\limits_{i=0}^{N+1}\alpha _{i,N,2}v_{i,N,2}
\]

\bigskip Por lo tanto, para cualquier capa $k$, se puede realizar lo
siguiente. 

\[
v_{0,n,k}=Sp_{n},\text{ \ \ };\text{\ \ \ }v_{i,n,k}=So_{i,k-1}\text{ \ };%
\text{\ \ \ \ }i\in \{1,2,...,N\}\text{ \ \ \ };\text{ \ \ \ }\alpha
_{N+1,n,k}=ms_{i,k}\text{ \ \ };\text{\ \ \ \ }%
v_{N+1,n,k}=RT1_{n,k}-RT2_{n,k}
\]

Con lo que se obtiene

\[
So_{n,k}=\dsum\limits_{i=0}^{N+1}\alpha _{i,n,k}v_{i,n,k}
\]
